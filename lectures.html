📑 ตารางสูตรลัดอ่านทบทวนด่วน (Quick Formula Sheet)

1. Fourier & Frequency Filters:

2D DFT: F(u,v) = Σ Σ f(x,y)·e^(-j2π(ux/M + vy/N))
Centering: f(x,y)·(-1)^(x+y) ➔ F(u - M/2, v - N/2)
ILPF: H = 1 if D ≤ D0 else 0 (Ringing สูงสุด)
BLPF: H = 1 / (1 + [D/D0]^(2n))
GLPF: H = exp(-D² / (2D0²)) (ไร้ Ringing 100%)

2. Image Restoration:

Degradation: g = f * h + η
Contraharmonic: f = Σ g^(Q+1) / Σ g^Q
• Q > 0 ➔ กำจัด Pepper (จุดดำ)
• Q < -1 ➔ กำจัด Salt (จุดขาว)
Wiener Filter: F = [ (1/H) · (|H|² / (|H|² + K)) ] · G

3. Segmentation & Evaluation:

Otsu Between-class: σ_B²(t) = ω0(t)·ω1(t)·(μ0(t) - μ1(t))²
เลือก t* = argmax σ_B²(t)
Accuracy = (TP + TN) / (TP + TN + FP + FN)
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
IoU = TP / (TP + FP + FN) (ไม่มี TN)

4. Texture & Edge:

Canny 5 Steps: Blur ➔ Gradient ➔ NMS ➔ DoubleThresh ➔ Hysteresis
Harris: R = det(M) - k·(trace(M))²
GLCM Contrast = Σ (i - j)² · p(i, j)
GLCM Homogeneity = Σ p(i, j) / (1 + (i - j)²)
GLCM Energy = Σ p(i, j)²

Lecture 1: Introduction to Image Processing & Generative AI

L1

บทนำสู่การประมวลผลภาพดิจิทัลและโมเดล Generative AI: ภาพรวมวิชา การแทนค่าภาพดิจิทัล ลำดับขั้นการประมวลผลภาพ และสถาปัตยกรรมโมเดล AI สังเคราะห์ภาพ (Stable Diffusion)

🔑 แนวคิดหลักและสูตรคำนวณ:
• Digital Image Representation
ภาพดิจิทัลคือฟังก์ชัน 2 มิติ f(x, y) ที่ถูกสุ่มตัวอย่าง (Sampling - พิกัดเชิงพื้นที่) และการแปลงเป็นค่าไม่ต่อเนื่อง (Quantization - ระดับความเข้มสี L = 2^k สำหรับ 8-bit คือ 0-255)
• Levels of Image Processing
1. Low-level: ภาพเข้า-ภาพออก (เช่น ปรับ Contrast, ลดสัญญาณรบกวน, Sharpening) 2. Mid-level: ภาพเข้า-ข้อมูลแอตทริบิวต์ออก (เช่น Edge detection, Segmentation, Object recognition) 3. High-level: ภาพเข้า-การตีความและทำความเข้าใจฉาก (Scene understanding, Autonomous driving)
• Generative AI Model Types
• Checkpoint (.safetensors): โมเดลหลักขนาดใหญ่ (~2-7GB) บรรจุ Weights ทั้งหมด (UNet, VAE, Text Encoder) • LoRA (Low-Rank Adaptation): โมเดลปรับแต่งเฉพาะจุดขนาดเล็ก (~50-200MB) ฝึกแทรกเลเยอร์ rank ต่ำ ไม่แก้โมเดลหลัก • Textual Inversion (Embeddings): ไฟล์ขนาดจิ๋ว (~10-100KB) สร้างเวกเตอร์คำเฉพาะตัวแทน concept ใหม่ใน Text Encoder • VAE (Variational Autoencoder): แปลงระหว่าง Pixel Space กับ Latent Space (บีบอัด 8x เพื่อประหยัดแรม) • Hypernetwork: โมเดลเครือข่ายขนาดเล็กที่มาคอยปรับน้ำหนักของ UNet ขณะสร้างภาพ
⚠️ หลุมพรางข้อสอบที่มักออกบ่อย:
  • ⚠️ ระวังความแตกต่างระหว่าง LoRA กับ Checkpoint: LoRA ไม่สามารถทำงานเดี่ยวๆ ได้ ต้องโหลดทับบน Base Checkpoint เสมอ
  • ⚠️ Sampling กำหนดความละเอียดเชิงพื้นที่ (Spatial Resolution: จำนวนพิกเซล) ส่วน Quantization กำหนดความละเอียดของระดับสี (Intensity Resolution: Gray levels)

Lecture 2: Control and Fine-tune (Stable Diffusion & ControlNet)

L2

การควบคุมและปรับแต่งพารามิเตอร์การสร้างภาพและ ControlNet: การตั้งค่าพารามิเตอร์ของกระบวนการ Denoising ใน Diffusion Model และการใช้ ControlNet หลากหลาย Preprocessor เพื่อควบคุมโครงสร้างภาพ

🔑 แนวคิดหลักและสูตรคำนวณ:
• Sampling Steps & Samplers
• Steps: จำนวนรอบของการ Denoising ยิ่งเยอะภาพยิ่งละเอียดแต่ช้าลง (จุดคุ้มค่าอยู่ที่ 20-30 steps) • Sampler Methods: อัลกอริทึมแก้สมการเชิงอนุพันธ์ (ODE/SDE) เช่น Euler (รวดเร็ว, deterministic), Euler a (ancestral, มีการสุ่ม noise ใหม่ทุก step ภาพไม่นิ่งเมื่อเพิ่ม steps), DPM++ 2M Karras (คุณภาพสูง คมชัด และลู่เข้าไว)
• CFG Scale & Denoising Strength
• CFG Scale (Classifier-Free Guidance): ค่าน้ำหนักความเคร่งครัดตาม Prompt (ค่าต่ำ = ภาพอิสระสร้างสรรค์, ค่าสูง = บังคับตาม prompt แต่ถ้าสูงเกิน >12 ภาพจะไหม้ contrast จัดและแตก) • Denoising Strength (ใน img2img): สัดส่วนของสัญญาณรบกวนที่ใส่เข้าไปในภาพเดิม (0 = ภาพเดิมไม่เปลี่ยน, 1 = ทิ้งภาพเดิมสร้างใหม่หมด)
• ControlNet Preprocessors
เครื่องมือดึงโครงสร้าง (Conditioning) จากภาพต้นฉบับ: • Canny: ตรวจจับขอบแบบละเอียด (ควบคุมโครงร่างวัตถุเป๊ะๆ) • OpenPose: ตรวจจับท่าทางโครงกระดูกมนุษย์ (กระดูก 18 จุด, มือ, หน้า) • Depth (Midas/DPT): แผนที่ความลึกมิติหน้า-หลัง (ควบคุมระยะชัดลึกและวัตถุบังกัน) • LineArt / Scribble: สกัดลายเส้นวาดมือหรือเส้นการ์ตูน • Tile: ควบคุมการ Upscale รายละเอียดสูงโดยไม่เปลี่ยนโครงสร้างรวม
• X/Y/Z Plot
สคริปต์ทดสอบตารางเปรียบเทียบ Grid ของพารามิเตอร์ต่างๆ (เช่น แนวนอนแกน X เปลี่ยน Sampler, แนวตั้งแกน Y เปลี่ยน CFG Scale, แกน Z เปลี่ยน Steps) เพื่อหาค่าที่เหมาะสมที่สุด
⚠️ หลุมพรางข้อสอบที่มักออกบ่อย:
  • ⚠️ Euler vs Euler a: Euler 'a' ย่อมาจาก Ancestral มีการเติม Random noise ในแต่ละรอบ ทำให้ผลลัพธ์ไม่ลู่เข้าหาภาพเดิมเมื่อเพิ่ม steps ต่างจาก Euler ธรรมดา
  • ⚠️ ถ้าเพิ่ม CFG Scale มากเกินไป ภาพจะเกิด Artifacts สีเพี้ยนรุนแรง (Over-saturation/Burning)

Lecture 3: Human Visual Perception

L3

ระบบการรับรู้ทางการมองเห็นของมนุษย์ (Human Visual System): กายวิภาคของดวงตามนุษย์ เซลล์รับแสง กลไกการปรับตัวต่อความสว่าง ปรากฏการณ์ภาพลวงตาทางสายตา และผลต่อการประมวลผลภาพ

🔑 แนวคิดหลักและสูตรคำนวณ:
• Anatomy of the Human Eye
• Cornea (กระจกตา): ผิวโปร่งแสงส่วนหน้า รวมแสงเบื้องต้น • Lens (เลนส์ตา): ปรับโฟกัสระยะใกล้-ไกล • Retina (จอประสาทตา): แหล่งรวมเซลล์รับแสง (Photoreceptors)
• Rods vs Cones
• Cones (เซลล์รูปกรวย): ~6-7 ล้านเซลล์ อยู่หนาแน่นที่สุดตรง Fovea Centralis รับผิดชอบ Photopic Vision (สภาวะแสงสว่างกลางวัน) ไวต่อสี (3 ชนิด: แดง เขียว น้ำเงิน) ให้ภาพคมชัดสูง • Rods (เซลล์รูปแท่ง): ~100 ล้านเซลล์ กระจายอยู่บริเวณรอบนอก (Periphery) รับผิดชอบ Scotopic Vision (สภาวะแสงสลัวกลางคืน) ไม่แยกสี ไวต่อแสงมาก ให้ภาพหยาบ
• Brightness Adaptation & Discrimination
ตามนุษย์ปรับระดับแสงได้กว้างมาก (10^10 เท่า) แต่ในชั่วขณะหนึ่ง (Subjective Brightness) จะปรับตัวอยู่ในช่วงจำกัด • Weber's Ratio: ΔIc / I โดย ΔIc คือความสว่างที่เปลี่ยนแปลงน้อยที่สุดที่ตามนุษย์แยกแยะได้ (Just Noticeable Difference)
• Visual Phenomena & Illusions
• Mach Bands: การเห็นแถบแสงสว่างเกินจริง (Overshoot) บริเวณขอบรอยต่อที่มีการเปลี่ยนระดับความเข้มแสง เกิดจาก Lateral Inhibition ของเซลล์ประสาทในจอตา • Simultaneous Contrast: ความสว่างที่เรารับรู้ไม่ได้ขึ้นกับค่าความเข้มสีจริงเพียงอย่างเดียว แต่ถูกอิทธิพลของสีพื้นหลังโดยรอบ (วัตถุสีเทาบนพื้นหลังดำจะดูสว่างกว่าวัตถุสีเทาเดียวกันบนพื้นหลังขาว) • Optical Illusions: ภาพลวงตาเชิงเรขาคณิต (เช่น Hermann grid, Kanizsa triangle) แสดงว่าสมองเติมแต่งข้อมูลที่ขาดหาย
⚠️ หลุมพรางข้อสอบที่มักออกบ่อย:
  • ⚠️ จำสลับ Cones กับ Rods: Cones = Color + Central (Fovea) + Bright light (Photopic); Rods = Night (Scotopic) + Periphery + Black/White
  • ⚠️ Mach bands ไม่ได้เกิดจากสัญญาณภาพจริง แต่เกิดจากกลไกประสาทตา (Lateral Inhibition)

Lecture 4: Point Operations & Intensity Transformation

L4

การดำเนินการระดับพิกเซล การแปลงระดับความเข้มสี และฮิสโทแกรม: การแปลงระดับความเข้มสีของพิกเซลเดี่ยว s = T(r), ฟังก์ชัน Linear, Log, Gamma, Bit-plane Slicing และการปรับปรุงภาพด้วย Histogram Equalization / Specification

🔑 แนวคิดหลักและสูตรคำนวณ:
• Intensity Transformation Functions
1. Linear: s = a*r + b (a ปรับ Contrast, b ปรับ Brightness) 2. Digital Negative: s = (L - 1) - r (กลับค่าสีขาวเป็นดำ ดำเป็นขาว สำหรับ 8-bit คือ 255 - r) 3. Logarithmic: s = c * log(1 + r) (ขยายย่านมืด บีบอัดย่านสว่าง นิยมใช้แสดงผล Fourier Spectrum) 4. Power-Law (Gamma): s = c * r^γ (ถ้า γ < 1 ภาพสว่างขึ้น ขยายย่านมืด; ถ้า γ > 1 ภาพมืดลง เพิ่ม Contrast ย่านสว่าง)
• Contrast Stretching vs Thresholding
• Contrast Stretching: การแปลงแบบ Piecewise-linear ขยายช่วง dynamic range ของภาพที่แคบให้เต็ม 0-(L-1) • Thresholding: การแปลงภาพ Grayscale ให้เป็นภาพ Binary (ขาว-ดำ) โดยกำหนดเกณฑ์ T: s = 255 ถ้า r >= T มิฉะนั้น s = 0
• Bit-Plane Slicing
การแยกพิกเซล 8-bit ออกเป็น 8 ระนาบ โดย Bit 7 (Most Significant Bit - MSB) บรรจุโครงสร้างและข้อมูลสายตาหลักส่วนใหญ่ ส่วน Bit 0 (LSB) บรรจุ noise สุ่มหรือใช้ซ่อนข้อมูลแบบ Steganography
• Histogram Equalization (HE)
การกระจายความถี่ของระดับสีให้สม่ำเสมอทั่วทั้งช่วง (Uniform Distribution) เพื่อเพิ่ม Global Contrast สูตรการคำนวณ: 1. หาความน่าจะเป็น p_r(r_k) = n_k / (M * N) 2. หาฟังก์ชันความหนาแน่นสะสม CDF: c_k = Σ p_r(r_j) จาก j=0 ถึง k 3. แปลงค่าระดับสีใหม่: s_k = round((L - 1) * c_k) คุณสมบัติ: เป็น Monotonically Increasing Function ทำให้รักษาระดับความสัมพันธ์ของเฉดสีเดิม
• Data Types: uint8 vs float32
• uint8: ค่าช่วง [0, 255] หากบวกเกิน 255 ใน OpenCV จะถูก saturate (cv2.add ปัดเป็น 255) แต่ถ้าคำนวณใน NumPy ดิบๆ จะเกิด Overflow หมุนกลับเป็นค่าต่ำ (เช่น 250 + 10 = 4) ดังนั้นต้องแปลงเป็น float32/float64 ก่อนคำนวณ แล้วใช้ np.clip(..., 0, 255).astype(np.uint8)
⚠️ หลุมพรางข้อสอบที่มักออกบ่อย:
  • ⚠️ Histogram Equalization สำหรับภาพดิจิทัล (Discrete) จะไม่สามารถให้ Flat Histogram แบบสมบูรณ์ 100% ได้ เพราะการจับกลุ่มค่า (Pixel grouping) และความไม่ต่อเนื่องของตัวเลขจำนวนเต็ม
  • ⚠️ การแปลง Log Transform ต้องระวังค่า r=0 จึงต้องใช้ log(1 + r) เพื่อป้องกัน log(0) ซึ่งหาค่าไม่ได้

Lecture 5: Spatial Filtering

L5

การกรองภาพในโดเมนเชิงพื้นที่ (Spatial Filtering): การประมวลผลเชิงเพื่อนบ้าน (Neighborhood Processing) การคอนโวลูชันและการคอร์ริเลชัน ฟิลเตอร์ปรับเรียบ ฟิลเตอร์ทางสถิติอันดับ ฟิลเตอร์เน้นขอบ (Laplacian, Unsharp Mask) และโมเดลสี

🔑 แนวคิดหลักและสูตรคำนวณ:
• Convolution vs Correlation
• Correlation: การเลื่อน Kernel ไปคูณแล้วบวกโดยตรงบนภาพ • Convolution: ต้องหมุน Kernel 180 องศา (Flip ทั้งแนวนอนและแนวตั้ง) ก่อนนำไปทำ Correlation (ถ้า Kernel มีความสมมาตร เช่น Gaussian หรือ Laplacian ทั้งสองตัวจะได้ผลลัพธ์เท่ากัน)
• Smoothing Spatial Filters (Lowpass)
• Box Filter: เมทริกซ์ 1/9 * ones(3, 3) เฉลี่ยเท่ากันทุกทิศทาง ลด noise ได้แต่ภาพเบลอและเกิดรอยสี่เหลี่ยม • Weighted Average: ให้น้ำหนักพิกเซลตรงกลางมากที่สุด เช่น 1/16 * [[1,2,1],[2,4,2],[1,2,1]] • Gaussian Filter: สร้างจากสมการเกาส์เซียน 2D ให้ความเรียบเนียนสูงสุดตามระยะทางห่างจากศูนย์กลาง
• Order-Statistic Filters (Nonlinear)
• Median Filter: เรียงลำดับค่าพิกเซลในหน้าต่างแล้วเลือกค่ามัธยฐาน มีประสิทธิภาพสูงสุดในการกำจัด Salt-and-Pepper Noise (Impulse Noise) โดยไม่ทำให้ขอบภาพเบลอเหมือนค่าเฉลี่ย • Min Filter: เลือกค่าน้อยสุด (กำจัดจุดสว่าง Salt Noise) • Max Filter: เลือกค่ามากสุด (กำจัดจุดมืด Pepper Noise)
• Sharpening Filters (Highpass & 2nd Derivative)
• Laplacian Operator: ตัวดำเนินการอนุพันธ์อันดับ 2 ไม่ขึ้นกับทิศทาง (Isotropic) หน้ากากมาตรฐาน 3x3 (ผลรวมเป็น 0): L1 = [[0, 1, 0], [1, -4, 1], [0, 1, 0]] L2 (รวมแนวทแยง) = [[1, 1, 1], [1, -8, 1], [1, 1, 1]] • สูตรการ Sharpening: g(x, y) = f(x, y) - ∇²f(x, y) (เมื่อตัวกลางของ Laplacian เป็นลบ) หรือ f(x, y) + ∇²f(x, y) (เมื่อตัวกลางเป็นบวก) • Unsharp Masking & High-boost Filtering: 1. เบลอภาพเดิม: f_blur = Lowpass(f) 2. หาหน้ากาก: g_mask = f - f_blur 3. เพิ่มความคมชัด: g = f + k * g_mask (ถ้า k=1 คือ Unsharp Masking, ถ้า k > 1 คือ High-boost Filtering)
• Color Models & Processing
• RGB: โมเดลแม่สีแสงบวก (Additive) เหมาะกับจอแสดงผล • CMY/CMYK: โมเดลแม่สีลบ (Subtractive) เหมาะกับการพิมพ์ • HSI/HSV: แยก Hue (เนื้อสี 0-360 องศา หรือ 0-179 ใน OpenCV), Saturation (ความอิ่มตัวสี 0-255), Value/Intensity (ความสว่าง 0-255) สอดคล้องกับการรับรู้ของมนุษย์ เหมาะกับงาน Color Segmentation
⚠️ หลุมพรางข้อสอบที่มักออกบ่อย:
  • ⚠️ จำเครื่องหมายในสมการ Sharpening กับเครื่องหมายศูนย์กลางของ Laplacian: ถ้าจุดกึ่งกลางของ Kernel เป็น -4 หรือ -8 ต้อง 'ลบ' ออกจากภาพเดิม (เพราะอนุพันธ์อันดับสองที่ขอบมีค่าตรงข้าม)
  • ⚠️ Median Filter เป็นตัวกรองแบบไม่เชิงเส้น (Non-linear filter) จึงไม่สามารถแทนด้วยการคูณ Convolution Kernel ปกติได้

Lecture 6: Frequency Domain Analysis (Fourier Transform)

L6

การวิเคราะห์ภาพในโดเมนความถี่ (Fourier Transform): ทฤษฎีการแปลงฟูริเยร์ 2 มิติ (2D DFT) สเปกตรัมขนาดและเฟส การเลื่อนตำแหน่งศูนย์กลาง การกรองสัญญาณในโดเมนความถี่ (ILPF, BLPF, GLPF) และปรากฏการณ์ Ringing Effect

🔑 แนวคิดหลักและสูตรคำนวณ:
• 2D Discrete Fourier Transform (DFT)
F(u, v) = Σ Σ f(x, y) * e^(-j*2π*(ux/M + vy/N)) การแปลงกลับ (IDFT): f(x, y) = (1/(MN)) * Σ Σ F(u, v) * e^(j*2π*(ux/M + vy/N)) • ความถี่ต่ำ (Low Frequencies): อยู่ใกล้จุดศูนย์กลาง แสดงถึงบริเวณพื้นผิวเรียบและเฉดสีที่ค่อยๆ เปลี่ยน • ความถี่สูง (High Frequencies): อยู่ห่างจากศูนย์กลาง แสดงถึงขอบภาพ (Edges) รายละเอียดคมชัด และสัญญาณรบกวน
• Centering the Spectrum (fftshift)
ตามปกติค่า F(0,0) (DC Component - ค่าเฉลี่ยความสว่าง) จะอยู่ที่มุมบนซ้าย (0, 0) การเลื่อนจุดกำเนิดมาไว้กึ่งกลางสเปกตรัมทำได้โดยการคูณภาพใน Spatial Domain ด้วย (-1)^(x+y) ก่อนทำ DFT หรือใช้ฟังก์ชัน np.fft.fftshift() หลังทำ DFT
• Fourier Spectrum & Dynamic Range
• Magnitude Spectrum: |F(u, v)| = sqrt(R(u,v)² + I(u,v)²) • Phase Spectrum: ϕ(u, v) = arctan(I(u,v) / R(u,v)) • Dynamic Range ของ |F| สูงมาก ค่า DC สูงกว่าความถี่อื่นเป็นหมื่นเท่า จึงต้องใช้ Log Transform เพื่อให้ตามองเห็น: S = c * log(1 + |F(u, v)|)
• Lowpass Filter Comparison
ระยะทางจากจุดศูนย์กลาง: D(u, v) = sqrt((u - M/2)² + (v - N/2)²) 1. Ideal Lowpass Filter (ILPF): H(u,v) = 1 ถ้า D <= D0 มิฉะนั้น 0 (ตัดสัญญาณคมกริบ เกิด Ringing Effect / Gibbs Phenomenon รุนแรงที่สุด) 2. Butterworth Lowpass Filter (BLPF): H(u,v) = 1 / (1 + [D/D0]^(2n)) (ความลาดเอียงขึ้นกับ Order n; ถ้า n=1 ไม่มี ringing, ถ้า n สูงขึ้นจะเริ่มมี ringing เล็กน้อย) 3. Gaussian Lowpass Filter (GLPF): H(u,v) = exp(-D² / (2*D0²)) (ราบเรียบ ไม่มีรอยหยัก Ringing Effect เกิดขึ้นเลย 100%)
• Highpass & Notch Filters
• Highpass Filter: H_HP(u, v) = 1 - H_LP(u, v) (ยอมให้ความถี่สูงผ่าน กรองความถี่ต่ำออก เน้นขอบภาพ) • Notch Filter: กรองเฉพาะจุดความถี่เฉพาะเจาะจง (u0, v0) และจุดสมมาตร (-u0, -v0) นิยมใช้ตัดสัญญาณรบกวนคาบเวลา (Periodic Noise)
⚠️ หลุมพรางข้อสอบที่มักออกบ่อย:
  • ⚠️ การทำ Frequency Domain Filtering จำเป็นต้องทำ Zero-padding ให้ขนาดเป็น P >= 2M และ Q >= 2N เพื่อป้องกันปัญหา Wrap-around Error (สัญญาณพันกลับมาชนกัน)
  • ⚠️ สาเหตุที่ ILPF เกิด Ringing Effect ในโดเมนเชิงพื้นที่ เพราะ Inverse Fourier Transform ของฟังก์ชันสี่เหลี่ยม (Boxcar) คือฟังก์ชัน Sinc ซึ่งมีคลื่นแกว่งลอน (Ripples)

Lecture 7: Image Restoration

L7

การฟื้นฟูสภาพภาพ (Image Restoration): แบบจำลองความเสื่อมถอย แบบจำลองสัญญาณรบกวน การกรองในโดเมนพื้นที่และการกรองความถี่ ตัวกรองเฉลี่ยอันดับสูง ตัวกรอง Wiener และการประมาณค่า Point Spread Function (PSF)

🔑 แนวคิดหลักและสูตรคำนวณ:
• Degradation Model
g(x, y) = f(x, y) * h(x, y) + η(x, y) ในโดเมนความถี่: G(u, v) = F(u, v)H(u, v) + N(u, v) เมื่อ f คือภาพจริง, h คือฟังก์ชันความเสื่อมถอย (PSF), η คือสัญญาณรบกวน (Noise)
• Noise Models
• Gaussian Noise: สัญญาณรบกวนทางความร้อนของวงจรเซนเซอร์ กระจายตัวแบบ Normal Curve • Salt-and-Pepper (Impulse) Noise: จุดขาวสุด (Salt=255) และจุดดำสุด (Pepper=0) เกิดจากการส่งสัญญาณผิดพลาด • Rayleigh, Gamma, Exponential: แบบจำลองสัญญาณรบกวนในระบบ Radar, เลเซอร์ หรือภาพทางการแพทย์ • Periodic Noise: สัญญาณรบกวนจากสนามแม่เหล็กไฟฟ้าแทรกซ้อน ปรากฏเป็นแถบคลื่นซ้ำๆ ในภาพ และเป็นจุดสว่างโดดเดี่ยว (Spikes) ใน Fourier Spectrum
• Restoration Spatial Filters
• Arithmetic Mean: 1/mn * Σ g(s, t) (ลด Gaussian noise) • Geometric Mean: [Π g(s, t)]^(1/mn) (คงรายละเอียดได้ดีกว่า Arithmetic Mean แต่ถ้ามีพิกเซลดำ 0 จะได้ผลเป็น 0 ทั้งบล็อก) • Harmonic Mean: mn / Σ [1/g(s, t)] (ใช้ได้ดีกับ Salt noise แต่ใช้กับ Pepper noise ไม่ได้) • Contraharmonic Mean: Σ g^(Q+1) / Σ g^Q - ถ้า Q > 0: กำจัด Pepper Noise (จุดมืด) - ถ้า Q < -1: กำจัด Salt Noise (จุดสว่าง) - ถ้า Q = 0: กลายเป็น Arithmetic Mean - ถ้า Q = -1: กลายเป็น Harmonic Mean
• Inverse vs Wiener Filtering
• Inverse Filter: F_hat(u,v) = G(u,v)/H(u,v) = F(u,v) + N(u,v)/H(u,v) (หาก H(u,v) มีค่าเข้าใกล้ศูนย์ หรือที่ความถี่สูง Noise จะถูกขยายมหาศาลจนภาพพัง ไม่เสถียรอย่างยิ่ง) • Wiener Filter (Minimum Mean Square Error - MMSE): F_hat(u, v) = [ (1/H(u,v)) * (|H(u,v)|² / (|H(u,v)|² + S_η/S_f)) ] * G(u, v) เมื่อ S_η/S_f คืออัตราส่วน Noise-to-Signal Power (มักประมาณด้วยค่าคงที่ K) แก้ปัญหาหารด้วยศูนย์ได้อย่างยอดเยี่ยม
⚠️ หลุมพรางข้อสอบที่มักออกบ่อย:
  • ⚠️ Contraharmonic Mean: จำแม่นๆ Q > 0 กำจัด Pepper (จุดดำ), Q < -1 กำจัด Salt (จุดขาว) ห้ามจำสลับ!
  • ⚠️ Image Enhancement เป็นเรื่องของ Subjective (ทำให้มนุษย์ดูแล้วพอใจ) ส่วน Image Restoration เป็นเรื่องของ Objective (ใช้แบบจำลองคณิตศาสตร์ย้อนกลับกระบวนการเสื่อมถอยเดิม)

Lecture 9: Edge and Corner Detection

L9

การตรวจจับเส้นขอบและมุม (Edge and Corner Detection): ตัวดำเนินการเกรเดียนต์ (Sobel, Prewitt, Roberts) อนุพันธ์อันดับสอง (LoG) อัลกอริทึม Canny Edge Detection 5 ขั้นตอน และการตรวจจับมุมของ Harris

🔑 แนวคิดหลักและสูตรคำนวณ:
• Image Gradient
เวกเตอร์การเปลี่ยนแปลงความเข้มสี: ∇f = [∂f/∂x, ∂f/∂y]^T • Magnitude: M(x, y) = sqrt(gx² + gy²) (บอกความคมชัดของขอบ) • Direction: θ(x, y) = arctan(gy / gx) (ทิศทางตั้งฉากกับแนวเส้นขอบ)
• Gradient Operators
• Roberts Cross: 2x2 mask (ตอบสนองเร็ว แต่อ่อนไหวต่อ noise สูงมาก) • Prewitt: 3x3 mask เฉลี่ยน้ำหนักเท่ากัน • Sobel: 3x3 mask ให้น้ำหนักตรงกลางเป็น 2 เพื่อช่วยลดสัญญาณรบกวนก่อนหาอนุพันธ์: Gx = [[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]] Gy = [[-1, -2, -1], [0, 0, 0], [1, 2, 1]]
• Canny Edge Detection (5 Steps)
1. Gaussian Smoothing: กรองลดสัญญาณรบกวนด้วยฟิลเตอร์เกาส์เซียน 2. Compute Gradient: คำนวณขนาดและทิศทางเกรเดียนต์ด้วย Sobel 3. Non-Maximum Suppression (NMS): ตัดพิกเซลที่ไม่ใช่จุดสูงสุดในแนวตั้งฉากกับขอบ (Quantize ทิศทางเป็น 0°, 45°, 90°, 135°) เพื่อให้ขอบเหลือความหนาเพียง 1 พิกเซล 4. Double Thresholding: แบ่งขอบเป็น 3 กลุ่มด้วยค่า T_high และ T_low: - Strong edge (>= T_high): ยอมรับเป็นขอบแน่นอน - Weak edge (T_low <= r < T_high): รอการตรวจสอบ - Non-edge (< T_low): ทิ้งทันที 5. Edge Tracking by Hysteresis: คงค่า Weak edge ไว้เฉพาะจุดที่มีการเชื่อมต่อกับ Strong edge แบบ 8-connectivity
• Harris Corner Detection
พิจารณาการเปลี่ยนระดับความเข้มสีเมื่อเลื่อนหน้าต่างตรวจจับ (u, v): Auto-correlation Matrix / Structure Tensor: M = Σ w(x, y) * [[Ix², Ix*Iy], [Ix*Iy, Iy²]] วิเคราะห์ค่า Eigenvalues (λ1, λ2): • λ1, λ2 มีค่าน้อยทั้งคู่ -> บริเวณราบเรียบ (Flat region) • λ1 >> λ2 หรือ λ2 >> λ1 -> เส้นขอบ (Edge) • λ1, λ2 มีค่ามากทั้งคู่ -> จุดมุม (Corner) Harris Response Function: R = det(M) - k * (trace(M))² = (λ1*λ2) - k*(λ1 + λ2)² โดย k คือค่าคงที่เชิงประจักษ์ (0.04 - 0.06) - ถ้า R > 0 (มาก): เป็น Corner - ถ้า R < 0: เป็น Edge - ถ้า |R| น้อย: เป็น Flat
⚠️ หลุมพรางข้อสอบที่มักออกบ่อย:
  • ⚠️ จำลำดับ 5 ขั้นตอนของ Canny ให้ขึ้นใจ โดยเฉพาะขั้นตอน NMS (ทำให้เส้นขอบบาง 1 พิกเซล) และ Hysteresis Thresholding (เชื่อมโยง weak edge กับ strong edge)
  • ⚠️ ทิศทางของ Gradient เวกเตอร์ θ จะ 'ตั้งฉาก' (Perpendicular) กับทิศทางของแนวขอบ (Edge Direction)

Lecture 10: Morphological Processing & Evaluation Metrics

L10

การประมวลผลเชิงสัณฐานวิทยาและเมทริกซ์ความสับสน (Morphology & Metrics): การดำเนินการพื้นฐานบนภาพไบนารี (Dilation, Erosion, Opening, Closing) โครงสร้างเอลิเมนต์ (SE) ขั้นตอนวิธีทางสัณฐานวิทยา และการประเมินผลด้วย Confusion Matrix

🔑 แนวคิดหลักและสูตรคำนวณ:
• Structuring Element (SE)
เมทริกซ์ขนาดเล็ก (มักเป็น 3x3 หรือ 5x5) ที่มีจุดกำเนิด (Origin) กำหนดรูปร่างที่ต้องการสำรวจ เช่น รูปสี่เหลี่ยม (cv2.MORPH_RECT), รูปกากบาท (cv2.MORPH_CROSS), หรือรูปวงรี (cv2.MORPH_ELLIPSE)
• Dilation & Erosion
• Dilation (การขยายตัว) A ⊕ B: พิกเซลเป็น 1 ถ้า SE ทับกับ Foreground อย่างน้อย 1 จุด -> ขยายวัตถุให้โตขึ้น อุดรูโหว่ขนาดเล็ก และเชื่อมส่วนที่ขาดออกจากกัน • Erosion (การกร่อน) A ⊖ B: พิกเซลเป็น 1 ก็ต่อเมื่อ SE ทับอยู่ใน Foreground ทั้งหมด -> หดวัตถุให้เล็กลง ตัดติ่งแหลม และลบสัญญาณรบกวนเม็ดเล็กๆ ออก
• Opening & Closing
• Opening A ∘ B = (A ⊖ B) ⊕ B (กร่อนก่อนแล้วค่อยขยาย): - ลบจุดรบกวนขนาดเล็กนอกวัตถุ (False Positives) - ตัดสะพานเชื่อมบางๆ โดยไม่เปลี่ยนขนาดรวมของวัตถุ • Closing A • B = (A ⊕ B) ⊖ B (ขยายก่อนแล้วค่อยกร่อน): - เชื่อมรอยต่อที่แตกหักและอุดรูโหว่ขนาดเล็กภายในวัตถุ (False Negatives) - เชื่อมเส้นที่ขาดจากกัน (เช่น เส้น Barcode)
• Morphological Algorithms
• Boundary Extraction: β(A) = A - (A ⊖ B) (นำภาพเดิมลบด้วยภาพที่กร่อนแล้ว จะได้เส้นขอบรอบนอกความหนา 1 พิกเซล) • Hit-or-Miss Transform: A ⊛ B = (A ⊖ B1) ∩ (A^c ⊖ B2) (ใช้สำหรับตรวจจับรูปทรงหรือแพทเทิร์นเฉพาะเจาะจงในภาพ) • Hole Filling: X_k = (X_(k-1) ⊕ B) ∩ A^c ทำซ้ำจนกระทั่งลู่เข้า
• Confusion Matrix & Evaluation Metrics
ตาราง 2x2 ระหว่าง Actual vs Predicted: • TP: คาดการณ์ 1 และจริง 1 | TN: คาดการณ์ 0 และจริง 0 • FP (Type I Error): คาดการณ์ 1 แต่จริง 0 (ทายเกิน) • FN (Type II Error): คาดการณ์ 0 แต่จริง 1 (ทายตกหล่น) สูตรคำนวณ: 1. Accuracy = (TP + TN) / (TP + TN + FP + FN) 2. Precision = TP / (TP + FP) (ความแม่นยำเมื่อทายบวก) 3. Recall (Sensitivity) = TP / (TP + FN) (ความครอบคลุมของสิ่งที่ต้องหา) 4. Specificity = TN / (TN + FP) 5. F1-Score = 2 * (Precision * Recall) / (Precision + Recall) 6. IoU (Jaccard Index) = TP / (TP + FP + FN)
⚠️ หลุมพรางข้อสอบที่มักออกบ่อย:
  • ⚠️ Opening = Erode แล้ว Dilate (ลบจุดรบกวนภายนอก); Closing = Dilate แล้ว Erode (อุดรูโหว่และเชื่อมสะพานภายใน)
  • ⚠️ IoU (Intersection over Union) ตัวส่วนคือ (TP + FP + FN) โดย 'ไม่มี' TN มารวมด้วย ระวังอย่าจำสลับกับ Accuracy

Lecture 11: Image Segmentation

L11

การแบ่งส่วนภาพ (Image Segmentation): การแบ่งแยกส่วนประกอบของภาพ การกำหนดค่าขีดแบ่ง (Global/Local Thresholding) วิธีของ Otsu การแบ่งส่วนแบบอิงบริเวณ (Region Growing, Split and Merge) การจัดกลุ่ม (K-means, Hierarchical) และ Watershed

🔑 แนวคิดหลักและสูตรคำนวณ:
• Principles of Segmentation
การแบ่งภาพ R ออกเป็นบริเวณย่อย R1, R2, ..., Rn โดยที่: 1. ยูเนียนกันได้ภาพทั้งหมด: U Ri = R 2. ทุกบริเวณเป็น Disjoint: Ri ∩ Rj = ∅ (สำหรับ i ≠ j) 3. ภายในบริเวณเดียวกันมีคุณสมบัติสอดคล้อง: P(Ri) = TRUE 4. ต่างบริเวณมีคุณสมบัติต่างกัน: P(Ri U Rj) = FALSE
• Otsu's Thresholding Method
การหาค่าขีดแบ่ง T* ที่เหมาะสมที่สุดแบบอัตโนมัติ โดยการหาค่าที่ให้ความแปรปรวนระหว่างกลุ่มสูงสุด (Maximizing Between-Class Variance σ_B²): สูตรคำนวณ: σ_B²(t) = ω0(t) * ω1(t) * (μ0(t) - μ1(t))² เมื่อ: • ω0(t) = ความน่าจะเป็นสะสมของ Class 0 (พิกเซล <= t) • ω1(t) = 1 - ω0(t) (พิกเซล > t) • μ0(t) = ค่าเฉลี่ยความเข้มสีของ Class 0 • μ1(t) = ค่าเฉลี่ยความเข้มสีของ Class 1 เลือก t* = argmax σ_B²(t)
• Region-based Segmentation
• Region Growing: เริ่มต้นจากจุดเมล็ด (Seed Points) แล้วผนวกพิกเซลเพื่อนบ้านที่มีคุณสมบัติความต่างสีน้อยกว่าเกณฑ์ที่กำหนด ทำซ้ำจนไม่มีพิกเซลเข้าเกณฑ์ • Region Split and Merge: อาศัยโครงสร้างข้อมูล Quadtree: - Split: หากบล็อกใดไม่สอดคล้องเงื่อนไขความเป็นเนื้อเดียวกัน ให้ผ่าแบ่งเป็น 4 บล็อกย่อย - Merge: หากบล็อกติดกัน 2 บล็อกรวมกันแล้วยังคงเป็นเนื้อเดียวกัน ให้ยุบรวมเข้าด้วยกัน
• Clustering Algorithms
• K-Means: กำหนด K เซนทรอยด์ -> กำหนดแต่ละจุดพิกเซลไปยังเซนทรอยด์ที่ใกล้ที่สุด -> คำนวณตำแหน่งเซนทรอยด์ใหม่จากค่าเฉลี่ย -> วนซ้ำจนลู่เข้า • Hierarchical Clustering: มี 2 รูปแบบ: - Agglomerative (Bottom-up): เริ่มจากทุกจุดเป็น 1 คลัสเตอร์ แล้วค่อยๆ ยุบคู่ที่ใกล้ที่สุดเข้าด้วยกัน - Divisive (Top-down): เริ่มจากภาพทั้งหมดเป็น 1 คลัสเตอร์ใหญ่ แล้วค่อยๆ แตกย่อยออก
• Watershed Segmentation
มองภาพ Grayscale เสมือนภูมิประเทศที่มีภูเขา (ขอบภาพที่มีเกรเดียนต์สูง) และหุบเขา (Catchment basins - บริเวณเนื้อวัตถุ) จำลองการปล่อยน้ำท่วมขึ้นมา สร้างเขื่อน (Watershed lines) ตรงจุดที่น้ำจากสองแอ่งจะล้นมาชนกัน • ปัญหาหลัก: มักเกิดการแบ่งส่วนย่อยเกินไป (Oversegmentation) เนื่องจาก noise ในเกรเดียนต์ • วิธีแก้: ใช้ Marker-Controlled Watershed โดยกำหนดจุดมาร์กเกอร์ภายในวัตถุและพื้นหลังล่วงหน้า
⚠️ หลุมพรางข้อสอบที่มักออกบ่อย:
  • ⚠️ Otsu's Thresholding มุ่งเน้น 'Maximize Between-Class Variance' ซึ่งเทียบเท่ากับการ 'Minimize Within-Class Variance' (ผลรวมความแปรปรวนรวมทั้งหมดคงที่)
  • ⚠️ Watershed Algorithm มักใช้กับ 'Gradient Magnitude' ของภาพ ไม่ใช่ใช้กับภาพ Grayscale ดิบๆ โดยตรง

Lecture 12: Texture Description & Analysis

L12

การบรรยายลักษณะเนื้อสัมผัสของภาพ (Texture Description): ความหมายของ Texture คุณลักษณะทางสถิติอันดับหนึ่งจากฮิสโทแกรม เมทริกซ์ความร่วมเกิดของระดับเทา (GLCM) คุณลักษณะของ Haralick และ Local Binary Patterns (LBP)

🔑 แนวคิดหลักและสูตรคำนวณ:
• First-Order Histogram Statistics
วิเคราะห์จากการแจกแจงความถี่ระดับสีโดยไม่คำนึงถึงตำแหน่งเชิงพื้นที่: • Mean (m): ความสว่างเฉลี่ย m = Σ z_i * p(z_i) • Variance (σ²): ความเปรียบต่างความเข้มสี σ² = Σ (z_i - m)² * p(z_i) • Skewness (μ3): ความเบ้ของฮิสโทแกรม (สมมาตร = 0, เบ้ซ้าย/ขวา) • Kurtosis (μ4): ความโด่งของฮิสโทแกรม (ความแหลมคมของการกระจาย) • Uniformity (Energy): U = Σ p(z_i)² (สูงสุดเมื่อภาพมีสีเดียว) • Entropy: H = -Σ p(z_i) * log2(p(z_i)) (บอกความสุ่มไร้ระเบียบ)
• Gray-Level Co-occurrence Matrix (GLCM)
เมทริกซ์สถิติอันดับสอง P(i, j | d, θ) ที่นับจำนวนคู่พิกเซลที่มีระดับสี i และ j อยู่ห่างกันเป็นระยะทาง d ในทิศทางมุม θ • ทิศทางมาตรฐาน: 0° (แนวนอนขวา), 45° (ทแยงขวาบน), 90° (แนวตั้งลงล่าง), 135° (ทแยงซ้ายบน) • Symmetric GLCM: ทำเมทริกซ์ให้สมมาตรโดยบวกกับทรานสโพสของตัวเอง: P_sym = P + P^T • Normalized GLCM: p(i, j) = P(i, j) / Σ P (ทำให้ผลรวมสมาชิกทั้งหมดเท่ากับ 1.0)
• Haralick Texture Features
คุณลักษณะเด่นคำนวณจาก Normalized GLCM p(i, j): 1. Contrast = Σ Σ (i - j)² * p(i, j) (วัดการเปลี่ยนแปลงระดับสีเฉพาะที่ ยิ่งต่างเยอะค่ายิ่งสูง) 2. Dissimilarity = Σ Σ |i - j| * p(i, j) 3. Homogeneity (Inverse Difference Moment - IDM) = Σ Σ p(i, j) / (1 + (i - j)²) (สูงเมื่อสมาชิกเกาะกลุ่มอยู่แถวเส้นทแยงมุม i=j เนื้อสัมผัสเรียบเนียน) 4. Angular Second Moment (ASM / Energy) = Σ Σ p(i, j)² (วัดความสม่ำเสมอซ้ำซากของลวดลาย) 5. Entropy = -Σ Σ p(i, j) * log2(p(i, j)) (วัดความซับซ้อนไร้ทิศทางของลวดลาย) 6. Correlation = Σ Σ [(i - μ_x)(j - μ_y) * p(i, j)] / (σ_x * σ_y)
• Local Binary Patterns (LBP)
การสกัดคุณลักษณะเนื้อสัมผัสแบบ Local Texture Operator: 1. กำหนดหน้าต่าง 3x3 รอบพิกเซลศูนย์กลาง (gc) 2. ทำ Threshold พิกเซลรอบข้างทั้ง 8 ตัว: ถ้า gp >= gc ให้ค่าเป็น 1 มิฉะนั้น 0 3. นำเลขฐานสอง 8 บิตมาคูณถ่วงน้ำหนัก 2^0 ถึง 2^7 แล้วรวมเป็นรหัสทศนิยม LBP (0-255) 4. สร้างฮิสโทแกรมของค่า LBP ทั้งภาพมาใช้เป็น Feature Vector
⚠️ หลุมพรางข้อสอบที่มักออกบ่อย:
  • ⚠️ Contrast vs Homogeneity ของ GLCM จะมีพฤติกรรมตรงกันข้ามกัน: ถ้าภาพมีลวดลายคมชัดหยาบ Contrast จะสูง Homogeneity จะต่ำ; ถ้าภาพเรียบเนียนเนื้อมะเนียน Homogeneity จะสูง Contrast จะต่ำ
  • ⚠️ First-Order Statistics ไม่สามารถบอกข้อมูลทิศทาง (Directionality) หรือระยะห่างเชิงพื้นที่ได้ จึงต้องใช้ Second-Order Statistics อย่าง GLCM
