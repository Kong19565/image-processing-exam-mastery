Lecture 1 - 12

📑 ตารางสรุปสูตรลัดและอัลกอริทึม (Quick Formula Reference)

อ่านทวนก่อนเข้าห้องสอบ

1. โดเมนความถี่และฟิลเตอร์ (Fourier & Frequency)

2D DFT:
F(u, v) = Σ Σ f(x, y) · e^(-j·2π·(ux/M + vy/N))

Spectrum Centering:
f(x, y) · (-1)^(x + y) ⟺ F(u - M/2, v - N/2)

Ideal Lowpass (ILPF):
H(u,v) = 1 if D(u,v) ≤ D0 else 0 (Ringing สูงสุด)

Butterworth Lowpass (BLPF):
H(u,v) = 1 / (1 + [D(u,v)/D0]^(2n))

Gaussian Lowpass (GLPF):
H(u,v) = exp(-D(u,v)² / (2·D0²)) (ไร้ Ringing 100%)

Gaussian Notch Reject Filter:
H(u,v) = 1 - exp(-D_k(u,v)² / (2·D0²))

2. การฟื้นฟูสภาพภาพ (Image Restoration)

Degradation Model: g = f * h + η

Contraharmonic Mean Filter:
f_hat = Σ g^(Q+1) / Σ g^Q
• Q > 0 ➔ กำจัด Pepper Noise (จุดดำ)
• Q < -1 ➔ กำจัด Salt Noise (จุดขาว)

Wiener Filter (MMSE):
F_hat = [ (1/H) · (|H|² / (|H|² + K)) ] · G

3. การแบ่งส่วนภาพและการประเมิน (Segmentation & Metrics)

Otsu's Between-Class Variance:
σ_B²(t) = ω0(t) · ω1(t) · (μ0(t) - μ1(t))²
เลือก t* = argmax σ_B²(t)

Evaluation Metrics:
• Accuracy = (TP + TN) / (TP + TN + FP + FN)
• Precision = TP / (TP + FP)
• Recall = TP / (TP + FN)
• F1-Score = 2·(Prec · Rec) / (Prec + Rec)
• IoU = TP / (TP + FP + FN) (ไม่มี TN)

4. เนื้อสัมผัสและขอบ (Texture & Edge)

Canny 5 Steps:
1. Gaussian Blur ➔ 2. Sobel Gradient ➔ 3. NMS Thinning ➔ 4. Double Threshold ➔ 5. Hysteresis Tracking

Harris Corner Response:
R = det(M) - k·(trace(M))² = (λ1·λ2) - k·(λ1 + λ2)²

Haralick Texture (GLCM):
• Contrast = Σ (i - j)² · p(i, j)
• Homogeneity = Σ p(i, j) / (1 + (i - j)²)
• Energy (ASM) = Σ p(i, j)²
• Entropy = -Σ p(i, j) · log2(p(i, j))
