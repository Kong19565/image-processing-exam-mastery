📋 ยุทธศาสตร์การพิชิตข้อสอบปลายภาค (Exam Strategy Blueprint)

💻 1. ข้อสอบแล็บปฏิบัติการ (Python OpenCV)

  • ต้องส่งเป็นไฟล์ .py ที่ตั้งชื่อตรงตามคำสั่งอย่างเคร่งครัด
  • ต้องเขียน Comment อธิบายขั้นตอนเป็นภาษาไทย ใน Source Code ทุกขั้นตอน
  • Binary Mask ต้องใช้ค่าสีขาว = 255 และสีดำ = 0 เท่านั้น
  • ต้องแปลงเป็น float32 ก่อนคำนวณเลข แล้วใช้ np.clip(..., 0, 255).astype(np.uint8) ป้องกัน overflow

📐 2. ข้อสอบทฤษฎีและการคำนวณ (Theory & Math)

  • Histogram Equalization: จำสูตรการแมปด้วยสะสม CDF × (L-1)
  • Fourier Filters: ILPF เกิด Ringing effect สูงสุด, GLPF ไร้ Ringing 100%
  • Contraharmonic Filter: Q > 0 กำจัด Pepper (จุดดำ), Q < -1 กำจัด Salt (จุดขาว)
  • Canny Edge: ไล่ 5 ขั้นตอนให้แม่น (Smooth ➔ Gradient ➔ NMS ➔ Double Thresh ➔ Hysteresis)
  • Otsu Method: หา $t^*$ ที่ให้ Between-class variance $\sigma_B^2(t)$ สูงสุด
