Q1 ข้อ 1: Intensity Transformation (การปรับระดับความเข้มสีเพื่อเปิดเผยวัตถุที่ซ่อนอยู่)

สถานการณ์โจทย์: ภาพมีวัตถุลึกลับ (เครื่องบิน) ซ่อนอยู่ในบริเวณท้องฟ้าซึ่งมีความสว่างจัดจนกลืนไปกับพื้นหลัง กำหนดให้ 'ลด Contrast' และ 'เพิ่ม Brightness' เพื่อให้วัตถุปรากฏชัดเจน พร้อมพล็อตและบันทึกกราฟฮิสโทแกรมก่อนและหลัง

ผลลัพธ์ที่ต้องส่ง (ตามระเบียบข้อสอบ):
  • Result1.png (ภาพผลลัพธ์ที่เห็นวัตถุชัดเจน)
  • Result1-Hist-Before.png (กราฟฮิสโทแกรมก่อนประมวลผล)
  • Result1-Hist-After.png (กราฟฮิสโทแกรมหลังประมวลผล)
  • Sketch รูปกราฟ Intensity Transformation s = T(r)
📐 แนวคิดคณิตศาสตร์ & อัลกอริทึม:

สมการเชิงเส้นทั่วไป: s = a * r + b • การลด Contrast: กำหนดความชัน 0 < a < 1 (เช่น a = 0.5 หรือ 0.6) ทำให้ช่วงระดับสีที่เกาะกลุ่มกันกระจายตัวแคบลง ความเปรียบต่างลดลง • การเพิ่ม Brightness: กำหนดค่าคงที่ b > 0 (เช่น b = 80 ถึง 100) เพื่อยกฐานความสว่างโดยรวมขึ้น ดึงรายละเอียดในบริเวณที่จมอยู่ในย่านสีเฉพาะให้ปรากฏออกมา • การป้องกัน Overflow: ต้องแปลงภาพเป็น float32 ก่อนคำนวณ แล้วใช้ np.clip(s, 0, 255).astype(np.uint8) เพื่อป้องกันค่าม้วนกลับ

📝 โครงสร้างโค้ด Python Pipeline:
  1. 1. โหลดภาพด้วย cv2.imread(..., cv2.IMREAD_COLOR) หรือ IMREAD_GRAYSCALE
  2. 2. วาดและบันทึกฮิสโทแกรมก่อนประมวลผลด้วย plt.hist(img.ravel(), 256, [0, 256], color='steelblue')
  3. 3. แปลงภาพเป็น np.float32 เพื่อป้องกันปัญหา uint8 overflow
  4. 4. คำนวณการแปลงเชิงเส้น: s = a * r + b (โดย a < 1 และ b > 0)
  5. 5. ตัดขอบเขตค่าด้วย np.clip(s, 0, 255) แล้วแปลงกลับเป็น np.uint8
  6. 6. บันทึกผลลัพธ์ Result1.png ด้วย cv2.imwrite()
  7. 7. วาดและบันทึกฮิสโทแกรมหลังประมวลผล Result1-Hist-After.png
⚠️ จุดที่มักถูกหักคะแนนบ่อยที่สุด:
  • ⚠️ อย่าลืม np.clip! หากคำนวณบน NumPy uint8 ตรงๆ ค่าที่บวกเกิน 255 จะม้วนกลับ (Wrap-around) กลายเป็นสีดำด่าง
  • ⚠️ ต้องระวังการพล๊อตกราฟ Matplotlib: สเกลแกน X ต้องจำกัดที่ [0, 256] เสมอ
  • ⚠️ อย่าลืมวาดรูปกราฟสเก็ตช์ s = T(r): กราฟจะเป็นเส้นตรงตัดแกน Y ที่จุด (0, b) และมีความชัน a น้อยกว่า 1

Q2 ข้อ 2: Barcode Detection (การตรวจจับบาร์โค้ดที่ทนทานต่อการเลื่อนและการหมุน 180°)

สถานการณ์โจทย์: เครื่องสแกน Boarding Pass อาจเจอปัญหาตั๋วเลื่อนตำแหน่ง (Translation) และการกลับด้านซ้าย-ขวา/หมุน 180° ให้สร้างโปรแกรมระบุบริเวณบาร์โค้ด แสดงผลลัพธ์เป็นภาพขาว-ดำ (บาร์โค้ด = 255, อื่นๆ = 0)

ผลลัพธ์ที่ต้องส่ง (ตามระเบียบข้อสอบ):
  • Result2-1.png (มาสก์บาร์โค้ดของตั๋วแบบที่ 1)
  • Result2-2.png (มาสก์บาร์โค้ดของตั๋วแบบที่ 2)
📐 แนวคิดคณิตศาสตร์ & อัลกอริทึม:

• คุณสมบัติทิศทาง (Directionality): เส้นบาร์โค้ดมีลักษณะเป็นแถบแนวตั้งขนานกันจำนวนมาก จึงมีเกรเดียนต์ในแนวนอน (Horizontal Gradient) สูงมาก การใช้ Sobel X หรือ Scharr X (cv2.Sobel(gray, cv2.CV_32F, 1, 0, ksize=-1)) จะตอบสนองเฉพาะเส้นแนวตั้งและกรองตัวอักษรแนวนอนทิ้ง • ความทนทานต่อการหมุน 180°: เส้นตรงแนวตั้ง เมื่อหมุน 180 องศา ก็ยังคงเป็นเส้นแนวตั้งเดิม ทำให้คุณสมบัติทางเกรเดียนต์ไม่เปลี่ยนแปลง (Invariant) • การเชื่อมกลุ่ม (Morphological Closing): ใช้ Rectangular Structuring Element ที่มีความกว้างในแนวนอนมากกว่าแนวตั้ง (เช่น ขนาด 21x7 หรือ 25x5) เพื่อเชื่อมเส้นบาร์โค้ดแต่ละเส้นที่อยู่ติดกันให้หลอมรวมเป็นก้อนสี่เหลี่ยมทึบก้อนเดียว • การกรองพื้นที่ (Contour Filtering): หา Contour ภายนอก แล้วคัดเลือก Contour ที่มีพื้นที่ (Area) สอดคล้อง และมีสัดส่วนกว้าง/ยาว (Aspect Ratio) เป็นรูปสี่เหลี่ยมผืนผ้า

📝 โครงสร้างโค้ด Python Pipeline:
  1. 1. แปลงภาพเป็น Grayscale และเกาส์เซียนเบลอเล็กน้อย (ksize=3 or 5)
  2. 2. คำนวณเกรเดียนต์แนวนอนด้วย Scharr Operator: gradX = cv2.Sobel(gray, cv2.CV_32F, dx=1, dy=0, ksize=-1)
  3. 3. แปลงค่าสัมบูรณ์และปรับสเกลเป็น 8-bit: gradX = cv2.convertScaleAbs(gradX)
  4. 4. เบลอเพื่อลดสัญญาณรบกวนความถี่สูง และทำ Thresholding (Otsu หรือ Binary)
  5. 5. ใช้ Morphological Closing ด้วย Rectangular Kernel (cv2.MORPH_RECT, (21, 7)) เพื่อผสานเส้นบาร์โค้ด
  6. 6. ทำ Dilation/Erosion เล็กน้อยเพื่ออุดรูโหว่และลบจุดประ
  7. 7. หา Contours ด้วย cv2.findContours(..., cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
  8. 8. วาดมาสก์สีขาว (255) ทึบลงบนภาพสีดำ (0) ด้วย cv2.drawContours(mask, [target_contour], -1, 255, -1)
⚠️ จุดที่มักถูกหักคะแนนบ่อยที่สุด:
  • ⚠️ ห้ามใช้ Thresholding ปกติโดยไม่ผ่าน Sobel X เพราะตัวหนังสือในตั๋วจะติดมาด้วยทั้งหมด
  • ⚠️ ระวังการกำหนดขนาด Structuring Element ถ้ากว้างน้อยเกินไป เส้นบาร์โค้ดจะไม่เชื่อมกัน แต่ถ้าสูงเกินไปอาจล้นไปรวมกับข้อความอื่น

Q3 ข้อ 3: Green Sign Detection (การตรวจจับแผ่นป้ายสีเขียวที่ทนทานต่อการเลื่อนตำแหน่ง)

สถานการณ์โจทย์: ตรวจจับบริเวณแผ่นป้ายบอกทางสีเขียวบนท้องถนน เพื่อนำไปใช้ระบุข้อความต่อไป ผลลัพธ์แสดงแผ่นป้ายเป็นสีขาว (255) และส่วนอื่นเป็นสีดำ (0)

ผลลัพธ์ที่ต้องส่ง (ตามระเบียบข้อสอบ):
  • Result3.png (Binary Mask ของแผ่นป้ายสีเขียว)
📐 แนวคิดคณิตศาสตร์ & อัลกอริทึม:

• การแยกสีในปริภูมิ HSV: ในระบบสี RGB สีเขียวจะเปลี่ยนค่าตามความสว่างของแดดและเงา แต่ในปริภูมิ HSV ค่า Hue (เนื้อสี) จะคงที่ต่อการเปลี่ยนแปลงของแสงสว่าง (Light Invariance) • ช่วงค่าสีเขียวใน OpenCV (H: 0-179, S: 0-255, V: 0-255): กำหนด Lower = [35, 50, 50] และ Upper = [85, 255, 255] • การอุดรูโหว่ตัวอักษร: แผ่นป้ายสีเขียวจะมีตัวหนังสือสีขาว/สัญลักษณ์อยู่ข้างใน ซึ่งจะทำให้เกิด 'รูโหว่' (Holes) ในหน้ากากสี จึงต้องใช้ Morphological Closing ด้วยขนาด SE ใหญ่พอ (เช่น 15x15 ถึง 25x25) หรือใช้อัลกอริทึม Hole Filling • การกรองรูปร่าง: ป้ายจราจรเป็นสี่เหลี่ยมผืนผ้าทึบ ใช้ cv2.boundingRect() ตรวจสอบความทึบ (Solidity = Contour Area / Bounding Box Area) จะมีค่าสูงเกือบ 1.0

📝 โครงสร้างโค้ด Python Pipeline:
  1. 1. โหลดภาพ BGR และแปลงเป็น HSV ด้วย cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
  2. 2. สกัดพิกเซลสีเขียวด้วย cv2.inRange(hsv, lower_green, upper_green)
  3. 3. อุดรูตัวอักษรในป้ายด้วย Morphological Closing (cv2.MORPH_RECT, (17, 17))
  4. 4. กำจัด noise เล็กๆ ภายนอกด้วย Morphological Opening
  5. 5. หา Contours ภายนอก และคัดเลือก Contour ที่มีพื้นที่ใหญ่ที่สุดและมีอัตราส่วนสี่เหลี่ยมผืนผ้าที่ถูกต้อง
  6. 6. สร้างภาพผลลัพธ์สีดำล้วน แล้ววาดระบายสีขาว (255) ทับลงบนพื้นที่ของป้ายด้วย cv2.drawContours(..., -1, 255, thickness=-1)
⚠️ จุดที่มักถูกหักคะแนนบ่อยที่สุด:
  • ⚠️ ลืมอุดรูตัวอักษรสีขาวในป้าย! โจทย์ต้องการมาสก์แผ่นป้ายทึบทั้งแผ่น หากไม่อุดรูจะได้มาสก์ที่กลวง
  • ⚠️ พิกัดสีเขียวในธรรมชาติอาจมีใบไม้ติดมาด้วย การคัดเลือกด้วยพื้นที่ (Area) และความทึบ (Solidity / Bounding Rect) จะช่วยคัดใบไม้ออกได้อย่างสมบูรณ์

Q4 ข้อ 4: Periodic Noise Removal (การกำจัดสัญญาณรบกวนซ้ำซ้อนในโดเมนความถี่)

สถานการณ์โจทย์: ภาพตัวละคร Dio ถูกรบกวนด้วยสัญญาณรบกวน 2 ชนิด: จุดรบกวนแบบเกลือพริกไทย (Salt-and-Pepper) และแถบสัญญาณรบกวนลายทางซ้ำๆ (Periodic Noise) ให้เขียนโปรแกรมคืนสภาพภาพกลับสู่ภาพต้นฉบับคมชัด

ผลลัพธ์ที่ต้องส่ง (ตามระเบียบข้อสอบ):
  • Result4.png (ภาพผลลัพธ์ที่กำจัดสัญญาณรบกวนทั้งหมดออกไป)
📐 แนวคิดคณิตศาสตร์ & อัลกอริทึม:

การแก้ปัญหาต้องแบ่งเป็น 2 ลำดับขั้นตามลักษณะของสัญญาณรบกวน: 1. ขั้นที่ 1: กำจัด Impulse / Salt-and-Pepper Noise ด้วย Median Filter (ขนาด 3x3 หรือ 5x5) หรือ Selective Median Filter เพื่อเก็บรายละเอียดเส้นสายสำคัญ 2. ขั้นที่ 2: วิเคราะห์ Periodic Noise ในโดเมนความถี่ - แปลงภาพด้วย 2D Discrete Fourier Transform (np.fft.fft2) แล้วเลื่อนจุดศูนย์กลางด้วย np.fft.fftshift() - สัญญาณรบกวนแบบคาบจะปรากฏเป็นจุดสว่างโดดเด่นสมมาตร (Spikes / Bright Dots) ห่างจากจุดศูนย์กลาง - สร้าง Gaussian Notch Reject Filter เพื่อปิดกั้นเฉพาะพิกัดความถี่คู่นั้น (uk, vk) และ (-uk, -vk): Hk(u, v) = 1 - exp(-Dk(u,v)² / (2*D0²)) - นำสเปกตรัมคูณกับ Filter: G(u, v) = F(u, v) * H(u, v) - ทำ Inverse Shift (ifftshift) และ Inverse Fourier Transform (ifft2) 3. ขั้นที่ 3: Post-processing ด้วย Contrast Stretching และ Unsharp Masking เบาๆ เพื่อคืนความคมชัดของลายเส้น

📝 โครงสร้างโค้ด Python Pipeline:
  1. 1. อ่านภาพ Grayscale ด้วย cv2.imread(..., cv2.IMREAD_GRAYSCALE)
  2. 2. กรองจุด Noise ดำขาวด้วย cv2.medianBlur(img, 3)
  3. 3. แปลงเป็น float32 และคำนวณ FFT: F = np.fft.fftshift(np.fft.fft2(img_med))
  4. 4. คำนวณสเปกตรัมขนาด |F| เพื่อหาพิกัดคู่จุด Spike ของสัญญาณรบกวนคาบ
  5. 5. สร้าง Gaussian Notch Reject Filter คูณตัดความถี่ที่เป็น noise ทั้งหมด
  6. 6. แปลงกลับสู่โดเมนเชิงพื้นที่: img_restored = np.real(np.fft.ifft2(np.fft.ifftshift(G)))
  7. 7. ปรับช่วงความสว่างด้วย Contrast Stretching และทำ Unsharp Masking เล็กน้อย
  8. 8. ตัดขอบเขต np.clip(..., 0, 255).astype(np.uint8) และบันทึก Result4.png
⚠️ จุดที่มักถูกหักคะแนนบ่อยที่สุด:
  • ⚠️ พยายามใช้ spatial filter (เช่น Gaussian blur) กำจัดลายทาง periodic noise ผลคือภาพจะเบลอเละทั้งหมดและไม่ผ่านเกณฑ์! ต้องใช้ Notch Filter ใน Fourier Domain เท่านั้น
  • ⚠️ จุด Spike ใน Fourier Spectrum จะมาเป็นคู่สมมาตรเสมอ (uk, vk) และ (-uk, -vk) รอบจุดกึ่งกลาง (M/2, N/2) ต้องสร้าง Notch กรองทั้งสองจุดคู่กัน

cv2.imread(path, cv2.IMREAD_GRAYSCALE) อ่านภาพเป็น 1 Channel ขาว-ดำ ทันที ขนาดอาเรย์คือ (H, W)
cv2.getStructuringElement(cv2.MORPH_RECT, (w, h)) สร้าง Kernel รูปร่างสี่เหลี่ยม ใช้สำหรับเชื่อมเส้นบาร์โค้ดแนวนอน (w > h)
cv2.morphologyEx(img, cv2.MORPH_CLOSE, kernel) ทำ Closing (Dilate แล้ว Erode) ใช้อุดรูโหว่และเชื่อมสะพานที่ขาด
cv2.morphologyEx(img, cv2.MORPH_OPEN, kernel) ทำ Opening (Erode แล้ว Dilate) ใช้ตัดติ่งแหลมและลบจุดรบกวนเม็ดเล็ก
cv2.Sobel(gray, cv2.CV_32F, dx, dy, ksize=-1) คำนวณ Gradient (ksize=-1 คือ Scharr) dx=1, dy=0 ตรวจจับเส้นแนวตั้ง
cv2.findContours(..., cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE) หาเส้นโครงร่างภายนอกสุด ส่งคืน (contours, hierarchy)
cv2.drawContours(canvas, contours, -1, 255, thickness=-1) วาด Contour ทึบทั้งชิ้น thickness=-1 คือระบายสีทึบเต็มพื้นที่
np.clip(val, 0, 255).astype(np.uint8) จำกัดช่วงและแปลงเป็น 8-bit ต้องทำทุกครั้งหลังบวกลบคูณหารเมทริกซ์
